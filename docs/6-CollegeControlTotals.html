Forecasting the College Enrollment in WF-TDM region into the horizon year.

This notebook forecasts college enrollment for Utah’s major universities using a Weighted Participation Rate method with logarithmic regression. The approach estimates each university’s share of its surrounding college-age population, fits a smooth trend curve to that share, and multiplies by future population projections from the Kem C. Gardner Policy Institute.

# --- 2. Fetch & Cache Census Data ---
if not PATHS["census_cache"].exists():
    print(f"Fetching Census data to {PATHS['census_cache']}...")
    decennial_years = [2000, 2010, 2020]
    acs_years = [y for y in range(2009, 2024) if y not in decennial_years]
    data_frames = []
    for year in sorted(decennial_years + acs_years):
        try:
            if year in decennial_years:
                dataset = "dec/dhc" if year == 2020 else "dec/sf1"
                code_col = "DHC" if year == 2020 else "SF1"
            else:
                dataset, code_col = "acs/acs5", "ACS"
            year_codes = var_crosswalk[code_col].tolist()
            rename_map = dict(zip(year_codes, var_crosswalk["Label"]))
            df = get_census(
                dataset=dataset,
                variables=["NAME"] + year_codes,
                year=year,
                params={"for": "county:*", "in": "state:49"},
                return_geoid=True,
            )
            df = df.rename(columns={c: "NAME" for c in df.columns if c.upper() == "NAME"})
            df = df.rename(columns=rename_map)
            valid_cols = ["NAME"] + var_crosswalk["Label"].tolist()
            df = df[df.columns.intersection(valid_cols)].copy()
            df["Year"], df["Dataset"] = year, dataset
            data_frames.append(df)
            print(f"Fetched {year}")
        except Exception as e:
            print(f"Skipping {year}: {e}")
    if data_frames:
        PATHS["census_cache"].parent.mkdir(parents=True, exist_ok=True)
        pd.concat(data_frames, ignore_index=True).to_csv(PATHS["census_cache"], index=False)
        print("Census data cached successfully")
else:
    print(f"Using cached Census data from {PATHS['census_cache']}")

)

df_nhgis = pd.read_csv(nhgis_path)
df_ut = df_nhgis[df_nhgis["STATE"] == "Utah"].copy()

# 2. Select college-age columns (B57AE–B57AH = 18–19, 20, 21, 22–24)
target_prefixes = ["B57AE", "B57AF", "B57AG", "B57AH"]
value_cols = [
    c for c in df_ut.columns
    if any(c.startswith(p) for p in target_prefixes) and not c.endswith("M")
]
for col in value_cols:
    df_ut[col] = pd.to_numeric(df_ut[col], errors="coerce")

# 3. Melt to long format and parse year
df_long = df_ut.melt(
    id_vars=["COUNTY"], value_vars=value_cols,
    var_name="Variable", value_name="Population"
)
df_long["Suffix"] = df_long["Variable"].str[5:]
df_long["Year"]   = df_long["Suffix"].apply(
    lambda x: int(x) if len(x) == 4 else 2000 + int(x[:2])
)
df_long["Type"] = df_long["Suffix"].apply(
    lambda x: "Decennial" if len(x) == 4 else "ACS"
)

# 4. Prefer Decennial over ACS for 2010 and 2020
mask_drop = (
    ((df_long["Year"] == 2010) & (df_long["Type"] == "ACS")) |
    ((df_long["Year"] == 2020) & (df_long["Type"] == "ACS"))
)
df_clean = df_long[~mask_drop].copy()

# 5. Aggregate by county and year
df_agg = df_clean.groupby(["COUNTY", "Year"])["Population"].sum().reset_index()
df_agg["Geography"] = df_agg["COUNTY"].apply(
    lambda x: x if "County" in str(x) else str(x) + " County"
)

# 6. Pivot to wide format (counties as columns)
df_college_age_hist = (
    df_agg[df_agg["Geography"].isin(TARGET_COUNTIES)]
    .pivot(index="Year", columns="Geography", values="Population")
    .sort_index()
)

5 Forecast Enrollment

5.1 How the Model Works

NotePlain-Language Summary for Public Officials

The core question: How many students will each Utah university enroll as the population grows?

The answer in three steps:

  1. Define the market. Each university draws students from specific nearby counties. We assign weighted shares to reflect this — for example, UVU’s market is 85% Utah County and 15% Salt Lake County. We multiply each county’s 18–24 population by its weight to get the university’s addressable population.

  2. Measure the participation rate. Divide actual enrollment by that addressable population each year. This gives us a participation rate — “of every 100 college-age residents in UVU’s market, about 39 are enrolled at UVU.”

  3. Forecast where the rate is heading. Participation rates don’t grow forever. They rise fast early on, then level off as a market matures. We fit a logarithmic curve to the historical rate, which naturally captures this “fast-rise, then flatten” pattern without assuming a hard cap. We then apply the forecasted rate to future population projections from the Kem C. Gardner Policy Institute.

Built-in safeguards: A calibration shift ensures the forecast starts exactly at the 2023 actual enrollment. A regional control total ensures the combined enrollment of all universities never exceeds the historically observed share of the regional college-age population.

Model Equation:

\text{Enrollment}_{t} = \left(\alpha + \beta \cdot \ln(t) + \text{Shift}\right) \times \text{Weighted GPI Population}_{t}

where t = \text{Year} - 1999 (so t = 1 in the year 2000) and the Shift anchors the forecast to 2023 actuals.

Each university’s addressable market is a weighted combination of surrounding county populations. These weights reflect where students realistically commute or relocate from, based on geographic proximity and institution type.

Note on Ensign & Westminster: These are small, urban institutions with highly local draws centered on Salt Lake City. Their separate catchments reflect their distinct student geographies from the larger BYU system.

5.5 Step 4 — Logarithmic Regression Model

Why logarithmic? Participation rates follow a natural “diminishing returns” curve. Early growth is fast as universities expand access and programs. Over time, rates slow as the easily-reachable population saturates. A logarithmic function captures this shape without hard-coding a target or ceiling for any individual school.

\text{Rate}(t) = \alpha + \beta \cdot \ln(t), \quad t = \text{Year} - 1999

t starts at 1 in the year 2000, so \ln(1) = 0 — the intercept \alpha equals the predicted rate in 2000. Each additional year’s contribution shrinks as \ln(t) grows more slowly.

Validation: Models are trained on 2000–2019 and evaluated on the held-out 2020–2023 period to check predictive accuracy.

5.6 Step 5 — Calibration Shift

Census and GPI use different population methodologies, so their 2023 county population estimates differ. Without correction, the forecast would show an artificial jump at 2024. We prevent this by computing a shift factor for each school.

Step Description
1 Compute the model’s predicted participation rate for 2023 (Census scale)
2 Compute the implied GPI rate for 2023: actual 2023 enrollment ÷ backcasted GPI population
3 Shift = Implied GPI Rate − Model Predicted Rate
4 Add this shift to every future year’s predicted rate

The shift is typically negative (−0.04 to −0.10), meaning the GPI population base is larger than Census for the same area, so the same enrollment count implies a lower rate on the GPI scale.

5.7 Step 6 — Regional Control Total

What is a control total? A control total acts as a regional sanity check. Even if each university’s individual model looks reasonable, their combined enrollment shouldn’t grow beyond what the region’s college-age population can realistically support. We set a ceiling equal to the highest regional penetration rate ever observed historically (with a small 2% buffer for uncertainty).

\text{Regional Penetration Rate} = \frac{\sum \text{All University Enrollments}}{\sum \text{All 5-County 18-24 Pop}}

If any forecast year’s total enrollment would exceed this ceiling, all universities are scaled down proportionally — preserving each school’s relative share while respecting the regional limit.

5.8 Step 7 — Final Forecast (2024–2060)

For each future year:

  1. Compute the log model’s predicted rate: \hat{R}_{t} = \alpha + \beta \cdot \ln(t)
  2. Apply the calibration shift: R^{*}_{t} = \hat{R}_{t} + \text{Shift}
  3. Compute raw enrollment: E_{t} = R^{*}_{t} \times \text{GPI Weighted Pop}_{t}
  4. Sum all schools to get regional total
  5. Apply control total: if \sum E_{t} > \text{Ceiling} \times \text{Total GPI Pop}_{t}, scale all schools down proportionally

# Forecast Enrollment

## How the Model Works

::: {.callout-note title="Plain-Language Summary for Public Officials"}
**The core question:** How many students will each Utah university enroll as the population grows?

**The answer in three steps:**

1. **Define the market.** Each university draws students from specific nearby counties. We assign weighted shares to reflect this — for example, UVU's market is 85% Utah County and 15% Salt Lake County. We multiply each county's 18–24 population by its weight to get the university's *addressable population*.

2. **Measure the participation rate.** Divide actual enrollment by that addressable population each year. This gives us a *participation rate* — "of every 100 college-age residents in UVU's market, about 39 are enrolled at UVU."

3. **Forecast where the rate is heading.** Participation rates don't grow forever. They rise fast early on, then level off as a market matures. We fit a **logarithmic curve** to the historical rate, which naturally captures this "fast-rise, then flatten" pattern without assuming a hard cap. We then apply the forecasted rate to future population projections from the Kem C. Gardner Policy Institute.

**Built-in safeguards:** A *calibration shift* ensures the forecast starts exactly at the 2023 actual enrollment. A *regional control total* ensures the combined enrollment of all universities never exceeds the historically observed share of the regional college-age population.
:::

**Model Equation:**

$$\text{Enrollment}_{t} = \left(\alpha + \beta \cdot \ln(t) + \text{Shift}\right) \times \text{Weighted GPI Population}_{t}$$

where $t = \text{Year} - 1999$ (so $t = 1$ in the year 2000) and the *Shift* anchors the forecast to 2023 actuals.

---

## Step 1 — Define Addressable Markets (Catchment Weights)

Each university's *addressable market* is a weighted combination of surrounding county populations. These weights reflect where students realistically commute or relocate from, based on geographic proximity and institution type.

> **Note on WSU:** Weber State's participation rate will exceed 1.0 in some years. This is expected — WSU draws commuter students from across the region, including counties outside its tight catchment definition. The log regression handles this correctly; it is a modeling artifact, not a data error.

> **Note on Ensign & Westminster:** These are small, urban institutions with highly local draws centered on Salt Lake City. Their separate catchments reflect their distinct student geographies from the larger BYU system.

## Step 2 — Weighted Populations

### Historical Population (Census / NHGIS, 2000–2023)

NHGIS provides Decennial Census data for 2000 and 2010, and ACS 5-year estimates from 2011–2023. The gap years **2001–2009** are filled by linear interpolation between the 2000 and 2010 Decennial counts. This is standard practice when blending decennial benchmarks with annual estimates.

```{python}
# --- Interpolate Census data to fill 2001–2009 gap ---
# df_college_age_hist index: sparse (2000, 2010, 2011, ..., 2023)
# After reindex + interpolate: annual 2000–2023
df_census_full = (
    df_college_age_hist
    .reindex(range(2000, 2024))
    .interpolate(method="linear")
)

# --- Compute weighted historical populations ---
df_weighted_hist = pd.DataFrame(index=range(2000, 2024))
for key, weights in CATCHMENT_WEIGHTS.items():
    df_weighted_hist[key] = sum(
        df_census_full[county] * weight
        for county, weight in weights.items()
        if county in df_census_full.columns
    )

print("Weighted Historical Population — last 5 years:")
print(df_weighted_hist.tail().round(0).to_string())
```

### Projected Population (GPI, 2024–2060)

GPI projections start at 2025. We backcast **2023 and 2024** using the average year-over-year change over 2025–2027, keeping everything on the GPI scale. This backcasted 2023 value is used only for the calibration shift calculation; the actual 2023 enrollment anchors the forecast.

## Step 4 — Logarithmic Regression Model

**Why logarithmic?** Participation rates follow a natural "diminishing returns" curve. Early growth is fast as universities expand access and programs. Over time, rates slow as the easily-reachable population saturates. A logarithmic function captures this shape without hard-coding a target or ceiling for any individual school.

$$\text{Rate}(t) = \alpha + \beta \cdot \ln(t), \quad t = \text{Year} - 1999$$

$t$ starts at 1 in the year 2000, so $\ln(1) = 0$ — the intercept $\alpha$ equals the predicted rate in 2000. Each additional year's contribution shrinks as $\ln(t)$ grows more slowly.

**Validation:** Models are trained on 2000–2019 and evaluated on the held-out 2020–2023 period to check predictive accuracy.

```{python}
# ──────────────────────────────────────────────────────────────────────────────
# Log Regression: Rate(t) = α + β·ln(t),  t = Year − 1999
# ──────────────────────────────────────────────────────────────────────────────

log_models       = {}
model_metrics    = []
model_fit_data   = []
residual_data    = []

print(f"Training on 2000–{TEST_START_YEAR - 1} | Evaluating on {TEST_START_YEAR}–2023\n")
print(f"{'School':<10} {'α (intercept)':>15} {'β (ln slope)':>14} {'Train R²':>10} {'Test R²':>9} {'Test MAPE':>10}")
print("-" * 75)

for key in SCHOOL_KEYS:
    full_name = DISPLAY_NAMES[key]

    # Build feature: t = Year - 1999, feature = ln(t)
    rates_series = df_hist_rates[key].dropna()
    years_arr    = rates_series.index.values.astype(float)
    rates_arr    = rates_series.values
    t_arr        = years_arr - 1999
    ln_t         = np.log(t_arr).reshape(-1, 1)

    # ── Train / Test split ──
    train_mask = years_arr < TEST_START_YEAR
    test_mask  = ~train_mask

    ln_t_train   = ln_t[train_mask];   rates_train = rates_arr[train_mask]
    ln_t_test    = ln_t[test_mask];    rates_test  = rates_arr[test_mask]
    years_train  = years_arr[train_mask].astype(int)
    years_test   = years_arr[test_mask].astype(int)

    # ── Fit on training data ──
    model = LinearRegression().fit(ln_t_train, rates_train)
    log_models[key] = model

    alpha = float(model.intercept_)
    beta  = float(model.coef_[0])

    # ── Training metrics ──
    pred_train = model.predict(ln_t_train)
    pop_train  = df_weighted_hist.loc[years_train, key].values
    enroll_actual_train = df_ipeds.loc[years_train, key].values
    enroll_pred_train   = pred_train * pop_train

    r2_train   = r2_score(rates_train, pred_train)
    mape_train = mean_absolute_percentage_error(enroll_actual_train, enroll_pred_train)
    rmse_train = float(np.sqrt(mean_squared_error(enroll_actual_train, enroll_pred_train)))

    model_metrics.append({
        "University": full_name, "Dataset": "Train",
        "Alpha": alpha, "Beta_LnT": beta,
        "R2": r2_train, "MAPE": mape_train, "RMSE": rmse_train,
        "N": len(rates_train), "Intercept": alpha,
    })

    for yr, actual, pred in zip(years_train, enroll_actual_train, enroll_pred_train):
        model_fit_data += [
            {"Year": int(yr), "University": full_name, "Value": float(actual), "Type": "Actual (Train)"},
            {"Year": int(yr), "University": full_name, "Value": float(pred),   "Type": "Predicted (Train)"},
        ]
    for yr, resid_rate, pop in zip(years_train, rates_train - pred_train, pop_train):
        residual_data.append({
            "Year": int(yr), "University": full_name,
            "Residual": float(resid_rate * pop), "Dataset": "Train",
        })

    # ── Test metrics ──
    r2_test = mape_test = rmse_test = None
    if test_mask.any():
        pred_test  = model.predict(ln_t_test)
        pop_test   = df_weighted_hist.loc[years_test, key].values
        enroll_actual_test = df_ipeds.loc[years_test, key].values
        enroll_pred_test   = pred_test * pop_test

        r2_test   = r2_score(rates_test, pred_test)
        mape_test = mean_absolute_percentage_error(enroll_actual_test, enroll_pred_test)
        rmse_test = float(np.sqrt(mean_squared_error(enroll_actual_test, enroll_pred_test)))

        model_metrics.append({
            "University": full_name, "Dataset": "Test",
            "Alpha": alpha, "Beta_LnT": beta,
            "R2": r2_test, "MAPE": mape_test, "RMSE": rmse_test,
            "N": len(rates_test), "Intercept": alpha,
        })

        for yr, actual, pred in zip(years_test, enroll_actual_test, enroll_pred_test):
            model_fit_data += [
                {"Year": int(yr), "University": full_name, "Value": float(actual), "Type": "Actual (Test)"},
                {"Year": int(yr), "University": full_name, "Value": float(pred),   "Type": "Predicted (Test)"},
            ]
        for yr, resid_rate, pop in zip(years_test, rates_test - pred_test, pop_test):
            residual_data.append({
                "Year": int(yr), "University": full_name,
                "Residual": float(resid_rate * pop), "Dataset": "Test",
            })

    r2_test_str   = f"{r2_test:.3f}"   if r2_test   is not None else "—"
    mape_test_str = f"{mape_test*100:.1f}%" if mape_test is not None else "—"
    print(
        f"{key:<10} {alpha:>15.4f} {beta:>14.4f} "
        f"{r2_train:>10.3f} {r2_test_str:>9} {mape_test_str:>10}"
    )
```

## Step 5 — Calibration Shift

Census and GPI use different population methodologies, so their 2023 county population estimates differ. Without correction, the forecast would show an artificial jump at 2024. We prevent this by computing a **shift factor** for each school.

| Step | Description |
|------|-------------|
| 1 | Compute the model's predicted participation rate for 2023 (Census scale) |
| 2 | Compute the *implied GPI rate* for 2023: actual 2023 enrollment ÷ backcasted GPI population |
| 3 | `Shift = Implied GPI Rate − Model Predicted Rate` |
| 4 | Add this shift to every future year's predicted rate |

The shift is typically negative (−0.04 to −0.10), meaning the GPI population base is larger than Census for the same area, so the same enrollment count implies a lower rate on the GPI scale.

```{python}
# ──────────────────────────────────────────────────────────────────────────────
# Step 5: Calibration Shift
# ──────────────────────────────────────────────────────────────────────────────

shift_factors = {}
shift_summary = []

print(f"{'School':<10} {'Model Rate 2023':>16} {'Implied GPI 2023':>18} {'Shift':>10}")
print("-" * 58)

for key, model in log_models.items():
    t_2023    = 2023 - 1999                          # = 24
    ln_t_2023 = np.array([[np.log(t_2023)]])

    # Model-predicted rate at 2023 (Census scale)
    model_rate_2023 = float(model.predict(ln_t_2023)[0])

    # Actual 2023 enrollment (from IPEDS)
    actual_enroll_2023 = float(df_ipeds.loc[2023, key])

    # GPI backcasted weighted population for 2023
    gpi_pop_2023 = float(df_weighted_proj.loc[2023, key])

    # Implied rate on the GPI scale
    implied_gpi_rate_2023 = actual_enroll_2023 / gpi_pop_2023

    shift = implied_gpi_rate_2023 - model_rate_2023
    shift_factors[key] = shift

    print(
        f"{key:<10} {model_rate_2023:>16.4f} {implied_gpi_rate_2023:>18.4f} {shift:>10.4f}"
    )
    shift_summary.append({
        "School":            DISPLAY_NAMES[key],
        "Model_Rate_2023":   round(model_rate_2023, 4),
        "Implied_GPI_Rate":  round(implied_gpi_rate_2023, 4),
        "Shift":             round(shift, 4),
        "Enrollment_2023":   int(actual_enroll_2023),
        "GPI_Pop_2023":      int(round(gpi_pop_2023)),
    })

df_shift_summary = pd.DataFrame(shift_summary)
```

## Step 6 — Regional Control Total

**What is a control total?** A control total acts as a regional sanity check. Even if each university's individual model looks reasonable, their *combined* enrollment shouldn't grow beyond what the region's college-age population can realistically support. We set a ceiling equal to the highest regional penetration rate ever observed historically (with a small 2% buffer for uncertainty).

$$\text{Regional Penetration Rate} = \frac{\sum \text{All University Enrollments}}{\sum \text{All 5-County 18-24 Pop}}$$

If any forecast year's total enrollment would exceed this ceiling, all universities are scaled down proportionally — preserving each school's relative share while respecting the regional limit.

```{python}
# ──────────────────────────────────────────────────────────────────────────────
```

## Step 7 — Final Forecast (2024–2060)

For each future year:

1. Compute the log model's predicted rate: $\hat{R}_{t} = \alpha + \beta \cdot \ln(t)$
2. Apply the calibration shift: $R^{*}_{t} = \hat{R}_{t} + \text{Shift}$
3. Compute raw enrollment: $E_{t} = R^{*}_{t} \times \text{GPI Weighted Pop}_{t}$
4. Sum all schools to get regional total
5. Apply control total: if $\sum E_{t} > \text{Ceiling} \times \text{Total GPI Pop}_{t}$, scale all schools down proportionally

```{python}
# ──────────────────────────────────────────────────────────────────────────────
# Step 7: Final Forecast (2024–2060)
# ──────────────────────────────────────────────────────────────────────────────

FORECAST_YEARS = list(range(2024, 2061))

# Total GPI regional population (5 counties combined) for control total
df_total_gpi_pop = df_gpi_ext[TARGET_COUNTIES].sum(axis=1)

forecast_records   = []
forecast_by_year   = {}    # year → {school → raw_enrollment}
regional_rate_proj = []

for year in FORECAST_YEARS:
    t     = year - 1999
    ln_t  = np.array([[np.log(t)]])

    # Raw enrollment for each school
    raw = {}
    for key, model in log_models.items():
        model_rate   = float(model.predict(ln_t)[0])
        shifted_rate = model_rate + shift_factors[key]
        gpi_pop      = float(df_weighted_proj.loc[year, key])
        raw[key]     = max(0.0, shifted_rate * gpi_pop)

    forecast_by_year[year] = raw

    # ── Control total check ──
    total_raw     = sum(raw.values())
    total_gpi_pop = float(df_total_gpi_pop.loc[year])
    proj_rate     = total_raw / total_gpi_pop
    ceiling_enroll = PENETRATION_CEILING * total_gpi_pop

    if total_raw > ceiling_enroll:
        scale_factor = ceiling_enroll / total_raw
        capped = True
    else:
        scale_factor = 1.0
        capped = False

    regional_rate_proj.append({
        "Year":  year,
        "Rate":  proj_rate * scale_factor,
        "Type":  "Projected",
        "Capped": capped,
    })

    for key, raw_enroll in raw.items():
        final_enroll = int(round(raw_enroll * scale_factor))
        forecast_records.append({
            "Year":         year,
            "Univ_Code":    key,
            "University":   DISPLAY_NAMES[key],
            "Rate_Model":   round(float(log_models[key].predict(ln_t)[0]), 5),
            "Rate_Shifted": round(float(log_models[key].predict(ln_t)[0]) + shift_factors[key], 5),
            "Scale_Factor": round(scale_factor, 5),
            "Pop_GPI":      round(float(df_weighted_proj.loc[year, key]), 0),
            "Enrollment":   final_enroll,
            "Type":         "Projected",
        })

df_forecast = pd.DataFrame(forecast_records)

# Report any years where the control total was triggered
capped_years = [r["Year"] for r in regional_rate_proj if r["Capped"]]
if capped_years:
    print(f"⚠  Control total ceiling triggered in {len(capped_years)} years:")
    print(f"   First: {capped_years[0]}, Last: {capped_years[-1]}")
else:
    print("✓  Control total not triggered — all years within ceiling.")

# ── Save detailed output ──
df_forecast.to_csv(PATHS["forecast_output"], index=False)
print(f"\nForecast saved → {PATHS['forecast_output']}")
print(df_forecast.head(14).to_string(index=False))
```
