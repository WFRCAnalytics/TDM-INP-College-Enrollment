Forecasting the College Enrollment in WF-TDM region into the horizon year.

This notebook forecasts college enrollment for Utah’s major universities using a Weighted Participation Rate method. The approach estimates each university’s share of its surrounding college-age population, fits a linear trend to that share, applies a regional penetration ceiling as a control total, and multiplies by future population projections from the Kem C. Gardner Policy Institute.

6 Flagship Override

BYU and the University of Utah draw students nationally and internationally, making their enrollment largely independent of local Wasatch Front demographics. Tying their forecast to the regional college-age population via participation rates produces unrealistic trajectories as local cohort sizes fluctuate. Instead, we model each flagship’s enrollment directly as a function of time:

\text{Enrollment}(t) = \alpha + \beta \cdot t, \quad t = \text{Year} - 1999

This treats their historical enrollment trend as the best predictor of future enrollment, bypassing catchment weights, weighted populations, and participation-rate mechanics entirely. The resulting forecasts are then substituted back into the base linear forecast for BYU and UofU only; all other universities retain their original participation-rate projections.

## Step 4 — Linear Regression Model

We fit a linear trend to each university's historical participation rate:

$$\text{Rate}(t) = \alpha + \beta \cdot t, \quad t = \text{Year} - 1999$$

The model is trained on 2000–$(\text{TEST\_START\_YEAR}-1)$ and evaluated on $\text{TEST\_START\_YEAR}$–2023.

```{python}
print(f"Training on 2000–{TEST_START_YEAR - 1} | Evaluating on {TEST_START_YEAR}–2023\n")

for key in SCHOOL_KEYS:
    full_name    = DISPLAY_NAMES[key]
    rates_series = df_hist_rates[key].dropna()
    years_arr    = rates_series.index.values.astype(float)

    beta       = float(model.coef_[0])
    pred_train = model.predict(X_train)

    # ── Train metrics ─────────────────────────────────────────────────────────
    pop_train         = df_weighted_hist.loc[years_train, key].values

        enroll_act_test   = df_ipeds.loc[years_test, key].values
```

## Step 5 — Calibration Shift Calculation

```{python}
# ──────────────────────────────────────────────────────────────────────────────
# Step 5: Calibration Shift Calculation (Census -> GPI Scale Bridge)
# Computes a per-school additive shift in RATE units so the model passes
# exactly through the 2023 actual enrollment when CALIB_SHIFT = True.
# ──────────────────────────────────────────────────────────────────────────────
shift_factors = {}   # key → shift in rate units
shift_summary = []
t_2023 = 2023 - 1999

for key in SCHOOL_KEYS:
    model_rate_2023       = float(models_dict[key].predict(np.array([[t_2023]]))[0])
    actual_enroll_2023    = float(df_ipeds.loc[2023, key])
    gpi_pop_2023          = float(df_weighted_proj.loc[2023, key])
    implied_gpi_rate_2023 = actual_enroll_2023 / gpi_pop_2023

    shift = (implied_gpi_rate_2023 - model_rate_2023) if CALIB_SHIFT else 0.0
    shift_factors[key] = shift

    shift_summary.append({
        "School":           DISPLAY_NAMES[key],
        "Model_Rate_2023":  round(model_rate_2023, 4),
        "Implied_GPI_Rate": round(implied_gpi_rate_2023, 4),
        "Shift":            round(shift, 4),
    })

df_shift_summary = pd.DataFrame(shift_summary)
```

## Step 6 & 7 — Final Forecasts

```{python}
# ──────────────────────────────────────────────────────────────────────────────
# Step 6: Define Control Total Ceiling
# ──────────────────────────────────────────────────────────────────────────────
total_enroll_hist   = df_ipeds[SCHOOL_KEYS].sum(axis=1).loc[2000:2023]
total_pop_hist_5cty = df_census_full[TARGET_COUNTIES].sum(axis=1).loc[2000:2023]
regional_rate_hist  = (total_enroll_hist / total_pop_hist_5cty).dropna()

HIST_MAX_PENETRATION = float(regional_rate_hist.max())
PENETRATION_CEILING  = HIST_MAX_PENETRATION * 1.02   # 2% buffer above peak

# ──────────────────────────────────────────────────────────────────────────────
# Step 7: Forecast Loop — Linear Participation-Rate Model
# ──────────────────────────────────────────────────────────────────────────────
FORECAST_YEARS   = list(range(2024, 2061))
df_total_gpi_pop = df_gpi_ext[TARGET_COUNTIES].sum(axis=1)

forecast_records   = []
regional_rate_proj = []

for year in FORECAST_YEARS:
    t = year - 1999
    total_gpi_pop  = float(df_total_gpi_pop.loc[year])
    ceiling_enroll = PENETRATION_CEILING * total_gpi_pop

    # Compute raw enrollment for every school: Rate(t) × weighted GPI population
    raw = {}
    for key in SCHOOL_KEYS:
        model_rate = float(models_dict[key].predict(np.array([[t]]))[0])

        # Decay calibration shift to zero over 10 years for WESTMIN only
        if key == "WESTMIN":
            decay_factor = max(0.0, 1.0 - (year - 2023) / 10.0) if CALIB_SHIFT else 0.0
            active_shift = shift_factors[key] * decay_factor
        else:
            active_shift = shift_factors[key]

        gpi_pop  = float(df_weighted_proj.loc[year, key])
        raw[key] = max(0.0, (model_rate + active_shift) * gpi_pop)

    # Regional control total: scale all schools proportionally if ceiling exceeded
    total_raw = sum(raw.values())
    proj_rate = total_raw / total_gpi_pop

    if total_raw > ceiling_enroll:
        scale_factor = ceiling_enroll / total_raw
        capped = True
    else:
        scale_factor = 1.0
        capped = False

    regional_rate_proj.append({
        "Year": year, "Rate": proj_rate * scale_factor,
        "Type": "Projected", "Capped": capped,
    })
    for key, raw_enroll in raw.items():
        forecast_records.append({
            "Year": year, "Univ_Code": key,
            "University": DISPLAY_NAMES[key],
            "Enrollment": int(round(raw_enroll * scale_factor)),
            "Type": "Projected",
        })

df_forecast = pd.DataFrame(forecast_records)
df_forecast.to_csv(PATHS["forecast_output"], index=False)
```

# Flagship Override

BYU and the University of Utah draw students nationally and internationally, making their
enrollment largely independent of local Wasatch Front demographics. Tying their forecast
to the regional college-age population via participation rates produces unrealistic
trajectories as local cohort sizes fluctuate. Instead, we model each flagship's enrollment
directly as a function of time:

$$\text{Enrollment}(t) = \alpha + \beta \cdot t, \quad t = \text{Year} - 1999$$

This treats their historical enrollment trend as the best predictor of future enrollment,
bypassing catchment weights, weighted populations, and participation-rate mechanics entirely.
The resulting forecasts are then substituted back into the base linear forecast for BYU
and UofU only; all other universities retain their original participation-rate projections.

## Flagship Regression Fit
